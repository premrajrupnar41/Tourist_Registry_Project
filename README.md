Tourist Registry Project
A full-stack web application for browsing, adding, and managing tourist attractions.
Built using Spring Boot (Java), React.js, H2 Database.

Frontend
React.js
Axios
TailwindCSS
React Router
Backend
Spring Boot
Spring Data JPA
H2 In-Memory Database
How to Run Code :-

cd backend/touristregistry : ./mvnw spring-boot:run

cd frontend : npm start
